
# 🎬 Ejercicio: Sistema de Acceso al Cine

## 📋 Descripción

Crea un sistema de control de acceso para un cine utilizando JavaScript.

## 🎯 Objetivos

- Practicar el uso de constantes
- Implementar estructuras de control condicionales
- Manejar validaciones anidadas

## 📝 Instrucciones

### 1. Configuración Inicial

Crea un archivo llamado `cine.js`

### 2. Variables a Definir

- **`edad`**: Constante numérica (ejemplo: `15`)
- **`tieneEntrada`**: Constante booleana (`true` o `false`)

### 3. Lógica de Control de Acceso

#### Nivel 1: Validación de Entrada

- **Si NO tiene entrada** → Mostrar mensaje:
  ```
  "Debes comprar una entrada primero"
  ```

#### Nivel 2: Validación de Edad

Si tiene entrada, verificar la edad:

- **Menor de 18 años** → Mostrar mensaje:

  ```
  "Acceso denegado: Eres menor"
  ```
- **18 años o más** → Mostrar mensaje:

  ```
  "¡Bienvenido al cine!"
  ```

## 💡 Conceptos Clave

- Uso de `if`, `else if` y `else`
- Operadores lógicos
- Comparaciones numéricas

---

**Nota**: Utiliza `console.log()` para mostrar los mensajes en la consola.
